熱度題材觀察名單・量測位置，不做判斷
這張卡量測 9 檔常被歸類為「瓶頸理論／光通訊」題材股目前在自己過去一年走勢裡的位置：52週區間位階、短中長期報酬、量比、年化波動率。全部是回顧性算術，沒有評分、沒有排序、不代表「還會不會漲」。資料來源：證交所 STOCK_DAY（上市）+ 櫃買中心 tradingStock（上櫃），方法在 tools/fetch_momentum.py。
相關財金期刊理論（僅供參考，非投資建議）：
· Da, Engelberg & Gao (2011, Journal of Finance) — 用 Google 搜尋量量測「關注度」，發現關注度上升預測未來2週股價上漲，但一年內幾乎全數回吐。
· Barber & Odean (2008, Review of Financial Studies) — 散戶因為無法逐一分析全市場，傾向用「新聞多／成交量異常／單日暴漲」取代基本面分析來選股，這種關注度驅動的買進事後平均報酬為負。
· Jegadeesh & Titman (1993, Journal of Finance) — 動量效應存在但有明確時間窗口（3–12個月），第一年後異常報酬會逐步回吐。
· Barber, Lee, Liu & Odean（台灣全市場資料，Review of Financial Studies）— 台灣散戶因積極追進出場，整體年度虧損約當GDP的2.2%，個別組合落後大盤年化3.8個百分點。
定期定額財富累積試算・存錢邏輯，不綁定特定標的
這張卡不看你買哪一檔，只算「固定金額、固定時間投入」這個機制本身的數學。目的是存錢，不是選股，所以底下沒有任何股票代碼。
公式：FV = P₀(1+r)ⁿ + PMT×[(1+r)ⁿ−1]/r。定期定額買到的平均成本，數學上是價格的調和平均數，依 AM-HM 不等式恆 ≤ 算術平均價格——這是唯一能證明的優勢，不是報酬保證。
持倉自動追蹤・證交所收盤價
每個交易日收盤後（約下午2:30後）由 GitHub Actions 自動抓證交所收盤價回來，不是即時跳動的報價，是每天更新一次。抓不到的時候（連假、API 異常）會顯示上一次成功抓到的資料，不會讓頁面壞掉。

閒錢分配建議
槓桿疊加警示
負債 + 槓桿 ETF = 兩層槓桿 借 5.99% 的錢持有 2 倍槓桿標的，等於用 1.7 倍實質曝險去搏。單日 −5% 的大盤，會讓部位 −10%，而利息照樣計。
兩件常被忽略的機制：
① 波動耗損：槓桿 ETF 每日重設倍數，盤整盤越震盪、長期越偏離 2 倍。大盤 −10% 再 +11.1% 回到原點，2 倍標的卻回不去。
② 無法追繳但會被時間追繳：貸款不會斷頭，但每月 30,055 的還款壓力會逼你在最差的時點賣股變現，這是真正的風險。

比較保守的做法是把「還款準備金」與「投資部位」實體分開兩個帳戶，讓帳面波動不會影響繳款能力。
本工具做的是數學，不是建議。實際決策請考量你的工作穩定度、家庭責任與風險承受度，必要時諮詢合格理財或債務顧問。

-- 一筆貸款的最小可用欄位集
CREATE TABLE loan (
  id            TEXT PRIMARY KEY,
  institution   TEXT,          -- 銀行代碼
  product_type  TEXT,          -- MORTGAGE|CREDIT|INSTALMENT
  principal     BIGINT,        -- 原始撥款
  balance       BIGINT,        -- 目前本金餘額
  apr_bp        INT,           -- 年利率 basis point，819 = 8.19%
  rate_type     TEXT,          -- FIXED|FLOAT
  term_total    INT,
  term_paid     INT,
  payment       BIGINT,
  due_day       INT,
  maturity_date DATE,
  autopay_acct  TEXT,
  synced_at     TIMESTAMPTZ
);

CREATE TABLE loan_txn (
  loan_id  TEXT REFERENCES loan(id),
  posted   DATE,
  kind     TEXT,   -- DISBURSE|REPAY|FEE|PREPAY
  amount   BIGINT,
  balance_after BIGINT
);

# 每次同步後跑一輪，輸出 alerts
rule HIGH_APR_OUTLIER:
  when  loan.apr_bp > weighted_avg_apr * 1.8
  emit  ALARM "這筆利率明顯偏高，優先償還"

rule MATURITY_SHORTFALL:
  when  loan.maturity_date - today < 12 months
        and remaining_payments * payment < balance
  emit  CAUTION "到期前現金流不足以清償，可能有尾款"

rule DSR_BREACH:
  when  sum(loan.payment) / income > 0.40
  emit  ALARM "月付佔收入過高，新增負債前先降槓桿"

rule CASHFLOW_RELEASE:
  when  any loan closes within 6 months
  emit  INFO "釋出 {payment}/月，預設導向最高利率那筆"

rule AUTOPAY_COLLISION:
  when  count(loan by autopay_acct, due_day) > 1
  emit  CAUTION "同帳戶同日多筆扣款，需以合併金額檢核餘額"
